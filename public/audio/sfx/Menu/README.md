# Menu SFX

Distinct from UI_Buttons (which is the global click). Used for menu nav focus.

| File | Key | Description | Duration | Character |
|---|---|---|---|---|
| placeholder_hover.wav | menu.hover | Mouse/key focus change | ~80ms | Very soft tick, lower volume than click |
| placeholder_select.wav | menu.select | Confirmed item selection | ~200ms | Sharper confirm, slightly pitched up |
